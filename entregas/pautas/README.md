# entregas/pautas

Pautas de reunião feitas a partir da base: o que levar ao Júnior e ao Euclides para decidir ou para informar, em linguagem de reunião, com cabeçalho padrão e dependências declaradas.
Não entra aqui: decisão nova (a resposta da reunião volta para base/decisoes.md, com a palavra de quem decidiu), valor de fato copiado da ficha de fatos nem dado pessoal.
